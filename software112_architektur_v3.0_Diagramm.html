Hintergrund

Der Stack in Kürze

Drei Namen, die im Diagramm ständig auftauchen — kurz eingeordnet für alle, die nicht täglich damit arbeiten.

▲
Vercel
seit 2015 · Guillermo Rauch

Betreibt die „Frontend Cloud", auf der software:112 läuft: ein globales Netzwerk, das die Anwendung ausliefert und bei jedem git push automatisch neu baut und deployt. Vercel ist zugleich der Hersteller von Next.js.

S
Supabase
seit 2020 · Copplestone & Wilson

Offene Alternative zu Googles Firebase: liefert eine gehostete PostgreSQL-Datenbank direkt mit Login, Datei-Ablage, Live-Updates und feingranularer Zugriffskontrolle je Mandant — der Grund, warum kein separates Datenbank-Team nötig ist.

N
Next.js
Open Source · v16 (2026)

Kostenloses Framework auf Basis von React, mit dem software:112 tatsächlich programmiert ist. Bringt Server-seitiges Rendering und die Server-Actions mit, über die die Anwendung mit Supabase spricht.

Next.js = der Anwendungscode · Vercel = wo er läuft · Supabase = wo die Daten liegen
Quellen: vercel.com/blog, supabase.com/blog, nextjs.org/blog — Stand September 2026.
